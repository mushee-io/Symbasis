- ETH-PERP / BTC-PERP;
- green/red OHLC candles and volume;
- moving bid/ask depth;
- BUY/SELL fill tape;

## 0:25–0:48 — Onchain trade

1. Claim sUSDC if needed.
2. Approve the Vault.
3. Deposit test collateral.
4. Select ETH-PERP.
5. Set margin and leverage.
6. Run **ANALYZE TRADE** to show the advisory risk output.
7. Open LONG or SHORT in the wallet.

Say:

“The wallet remains the signer. Symbasis’s risk layer advises but never has custody or signing authority. The PerpEngine reserves isolated margin in the Vault and settles PnL onchain.”

## 0:48–1:02 — Position and settlement

Show:

- position size;
- entry price;
- liquidation price;
- unrealized PnL;
- onchain activity / explorer link.

Then close the position.

Say:

“Closing releases reserved margin and settles PnL back into the collateral account. Our deployment workflow smoke-tested the full deposit-to-withdraw loop successfully.”

`Maximum 3x leverage. Reduce exposure during extreme volatility.`

“The raw mandate stays in the browser. Only its keccak256 commitment is written onchain. Public position state is not confidential yet, and we state that explicitly. The architecture is VELA-ready when shared Horizen deployment becomes available.”
